# Molecular drawing environments

The local records contain two RDKit environments: `kian-rdkit` (created 18 June 2026) and `my-rdkit-env` (created 10 November 2025). Schematic scripts ran in `kian-rdkit` during verification, but the records do not identify which environment produced each submitted figure.

The earlier molecular drawing script imports CairoSVG, for which no historical installation record was found. RDKit's native Cairo drawing support is a separate dependency.

The submitted Figure 3 is available as an [EMF file](../../figures/final_dissertation/Figure03_tacrine_tacrinium.emf) recovered from the Word document. Its original drawing application is unknown. See [figure provenance](../../docs/figure_provenance.md) for the archived files and script mapping.
